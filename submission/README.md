# Bike Sharing Dataset Dashboard

## Deskripsi
Dashboard interaktif ini dibuat untuk menganalisis data penyewaan sepeda (*Bike Sharing dataset*) berdasarkan kondisi cuaca, musim, serta pola perilaku tipe pengguna (*Casual* vs *Registered*).

## Setup Environment - Anaconda
```
conda create --name main-ds python=3.9
conda activate main-ds
pip install -r requirements.txt
```

## Setup Environment - Shell/Terminal
```
pip install -r requirements.txt
```

## Run Streamlit App
```
streamlit run dashboard.py
```
